# Facilitation Patterns

Machine-readable descriptions of facilitation methodologies and techniques.

## Structure

Each pattern is defined in YAML format following the schema in `schema/pattern.yaml`.

Patterns are organized by category:
- `deliberative/` - Methods for collective decision-making
- `generative/` - Methods for ideation and creativity
- `transformative/` - Methods for conflict resolution and perspective shifts

## Contributing Patterns

1. Use the pattern schema as your template
2. Include references to source methodology
3. Add practical examples where possible
